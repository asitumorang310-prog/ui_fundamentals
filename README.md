## REST API

Aplikasi menggunakan REST API latihan untuk Course Data Manager.

- Base URL: `https://course-api-pearl.vercel.app`
- Endpoint GET: `/courses`
- Method: `GET`
- Status Code berhasil: `200 OK`

Contoh field JSON yang digunakan:

```json
{
  "id": 1,
  "code": "MOB01",
  "title": "Git & GitHub",
  "credits": 2,
  "status": "active"
}
```
